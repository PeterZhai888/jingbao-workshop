# 镜爆工坊「AI视频」分镜 Prompt 第三轮优化

## 一、优化背景

真实测试发现，目前 AI 视频生成存在明显的跨镜头连续性问题，例如：

- 上一镜头门在走廊左侧，下一镜头切到人物正面后，空间关系发生变化
- 上一镜头是单扇门，下一镜头变成双扇门
- 上一镜头餐桌上有一桌饭菜，下一镜头饭菜数量明显变化
- 上一镜头没有明确建立人物位置，下一镜头人物突然出现
- 前一镜头建立的场景、道具、人物状态没有被后续镜头稳定继承

因此本次只优化「🤖 AI视频 Prompt」的跨镜头连续性。

---

# 二、增加“四类连续性”要求

AI视频分镜必须同时考虑：

### 1. 人物连续性

同一角色跨镜头保持：

- 年龄
- 发型
- 主要面部特征
- 发色
- 服装
- 身材和整体形象

一致。

除非剧情明确要求，否则不得随意改变。

---

### 2. 场景连续性

同一连续场景必须保持：

- 房间/环境布局
- 门窗位置
- 墙体位置
- 家具位置
- 主要空间关系

一致。

例如：

如果第一镜头已经建立「白色单扇门位于走廊左侧」，后续镜头必须继续继承这一空间关系，不得重新生成成另一种门或改变门的位置。

---

### 3. 道具连续性

重要道具必须保持连续：

- 外观
- 类型
- 数量
- 位置
- 当前状态

例如：

上一镜头餐桌上已经建立四道菜和一碗汤，后续镜头继续表现同一张餐桌时，应默认继承该饭菜状态，除非剧情明确要求发生变化。

---

### 4. 状态连续性

后续镜头必须继承上一镜头结束时已经建立的动作和状态。

例如：

- 门由关闭变为打开 → 后续镜头默认门已经打开
- 人物从门口走向餐桌 → 后续镜头应继承人物已经进入房间
- 女友上一镜头坐在餐桌旁 → 后续镜头不能无理由让女友凭空消失或重新出现
- 人物已经拿起某个道具 → 后续镜头默认继续持有，除非剧情明确放下

---

# 三、增加「镜头继承机制」

请在 Prompt 中增加以下核心原则：

> **每一个镜头都必须继承前一个镜头已经建立的人物、场景、重要道具和状态。除非剧情明确要求发生变化，否则不得重新随机设定。**

生成每一个新镜头时，应主动检查：

1. 上一镜头有哪些人物？
2. 人物在哪里？
3. 人物当前是什么动作/状态？
4. 场景是什么？
5. 场景中的重要空间关系是什么？
6. 有哪些关键道具？
7. 道具当前是什么状态？
8. 本镜头发生了什么变化？

只有剧情明确发生变化时，才修改对应元素。

---

# 四、增加内部「continuity」信息

为了提高模型跨镜头连续性，可以在生成过程中建立内部的连续性信息。

例如：

continuity:
「继承上一镜头的客厅空间布局；白色单扇入户门位于走廊左侧；餐桌位于客厅右侧靠墙位置；餐桌保持四道菜和一碗汤；女友已经坐在餐桌旁。」

下一镜头继续继承这些信息，只描述本镜头发生的新动作。

该 continuity 信息：

- 作为 Prompt 内部控制信息使用
- 不要求用户填写
- 不要求前端展示
- 不改变现有前端字段结构
- 不改变现有 JSON 对外输出结构

---

# 五、AI视频 Prompt 的最终原则

AI视频模式不只是描述「这个镜头长什么样」，还必须解决：

> **“这个镜头与上一镜头是什么关系？”**

因此生成逻辑从：

「单镜头画面描述」

升级为：

> **「当前画面 + 上一镜头状态 + 必须继承的视觉元素 + 本镜头发生的变化」**

重点保证：

**人物连续 + 场景连续 + 道具连续 + 状态连续。**

---

# 六、本次不要修改

不要修改：

- 前端界面
- 用户输入方式
- 现有 JSON 对外字段
- 真人实拍 Prompt
- 混合创作 Prompt
- 自动识别逻辑
- 镜头数量规则

不要增加用户需要填写的「人物设定」「场景设定」「道具设定」等复杂操作。

目标是：

> **让后台 Prompt 更专业，让用户界面继续保持简单。**

完成后直接用真实 AI 视频生成进行测试。
